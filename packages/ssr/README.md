# @liqvid/ssr

This package contains some utilities to support server-side rendering.

**Note:** this exists primarily to support projects using Webpack (e.g. Docusaurus). If you are using Vite or Turbopack, prefer `import.meta.env.*` directly:

- [Vite docs](https://vite.dev/guide/env-and-mode#built-in-constants)
- [Turbopack docs](https://nextjs.org/docs/app/api-reference/turbopack#importmetaenv)
